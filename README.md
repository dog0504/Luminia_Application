# プロジェクト概要

### ■ プロジェクト名：Luminia

AIを活用した派遣会社専用の人材検索・推薦業務を効率化するシステムです。

### ■ 目的・背景

時間が長くかかるとメリットはありますが、デメリットはプロジェクトを進む中で
期間を多くなることを考慮して企画しなきゃならないことになります。
僕は人材検索・推薦業務を効率化するとすのかかる時間が大分減らせることで、発展する
速度を結構高めると確信しました。

### ■ 要因・問題点

現在派遣市場ではAという企業から望む人材を見つけ、雇用するように形になっております。
通常TCD・顔合わせ・面談・契約・雇用・実践業務をするまでに平均10日から2週間程度かかる
と知っております。
最大は1ヶ月まではかかることもありそうです。

### ■ ターゲット

- 様々な分野で携わってる派遣会社
- 人材紹介を求めてる企業
